# Iteration 059 — 微练习审核未保存保护

## Before

- 诊断Gold审核会在表单修改后阻止切换案例，并在关闭或刷新时触发未保存提醒。
- 微练习审核没有同等保护：教师选择盲答、训练错因或六维判断后，点击上一题/下一题会直接重新渲染并丢失输入。
- 真实微练习审核仍为0/10，尚未发生外部数据损失。

## Change

- 第一阶段盲答表单和第二阶段六维表单统一追踪`formDirty`。
- 存在未保存输入时，上一题/下一题不会切换，并根据当前阶段提示先锁定盲判或保存六维审核。
- 页面关闭或刷新时使用`beforeunload`触发浏览器原生未保存提醒。
- 只有服务端成功返回并重新渲染已持久化状态后，才清除dirty状态。
- 增加静态回归断言，防止未保存保护被移除。

## After

- 173/173项自动化测试通过。
- 浏览器在第一题选择盲答与目标错因后点击“下一题”，位置保持`EXERCISE 1 / 10`并显示先锁定盲判的提示。
- 权威服务端进度仍为盲判0/10、Gold 0/10，浏览器验收没有提交教师结论。

## Regression

- 不改变两阶段审核协议、盲编号、Gold揭示条件或教师准入规则。
- 审核者编号与资质声明不是案例结论，不触发案例dirty状态；真正的盲答、错因、六维选择和说明会触发。
- 外部教师证据数量未增加，仍需教师真实完成10题。
