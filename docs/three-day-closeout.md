# Reading Lens — 三天收尾计划

## 收尾目标

三天后停止产品开发，交付一段可以在简历、作品集和面试中完整讲述的AI产品经历：

> 从雅思阅读教学中的真实问题出发，设计Evidence-first错因诊断流程，完成可运行MVP，建立规则与大模型评测，通过真实用户发现P004误诊和反馈价值问题，完成修复，并用修复后用户与独立教师证据验证迭代结果。

## 必须完成

1. **微练习独立教师审核10/10。** 用于回答“生成的练习是否真的针对错因且教学上成立”。
2. **修复后新用户复测3/3。** 用于回答“P004修复和反馈改写后，用户能否说出具体错点、下一步动作及练习关系”。
3. **完整Demo回归一次。** 从Answer到Transfer与Learner State，无阻塞、无答案泄漏、刷新不丢核心状态。
4. **冻结最终证据。** 导出脱敏结果，更新案例页、简历bullet、3分钟项目介绍和面试复盘。

## 可以做，但不阻塞收尾

- 诊断独立教师Gold从10条扩展到50条。
- DeepSeek v4 Prompt或再次付费回归。
- 7日复访和长期提分实验。
- 更多题型、题库、登录、部署和商业化功能。

以上统一记录为Future Improvements；除非发现核心流程阻塞或证据错误，否则不再开发。

## 三天安排

### Day 1

- 完成10条微练习两阶段独立教师审核。
- 若出现内容错误，只修复阻塞批准的具体题目；不重构练习系统。

### Day 2

- 完成3名修复后目标用户测试并保存记录。
- 对比首轮5人基线；只报告探索性变化，不声称提分。

### Day 3

- 运行最终tests/evals与完整Demo。
- 冻结证据并生成作品集、简历和面试材料。
- 达到下方停止条件后，明确停止开发。

## 停止开发条件

- 核心Demo无阻塞。
- 自动测试与免费评测通过。
- 微练习审核达到10/10，或如实记录未通过题目及一次修复。
- 修复后复测达到3/3，并能形成前后对比。
- 案例材料包含“问题—方案—MVP—评测—失败—迭代—结果—局限”。

满足以上条件即收尾，不再因非关键问题延长项目。
