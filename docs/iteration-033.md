# Iteration 033 — 教师审核可交接启动包

## Before

- 教师盲审页面与技术指南已经存在，但首次受邀老师需要产品负责人另行解释项目目的、资质要求、试审停点和恢复方式。
- 招募话术、预计耗时、匿名编号规则、并发冲突处理和试审后检查散落在多份工程文档中。
- 审核入口直接进入案例，没有先确认“先做10条、再决定是否继续”的研究边界。

## Change

- 新增`/review-start.html`作为可直接发送给老师的审核启动页。
- 页面说明适格审核者、匿名编号、原创合成数据、隐藏模型结果、固定五步因果链、10条试审、20–30分钟估计、暂停恢复、并发冲突和50条前不出正式结论。
- 提供可直接发送的邀请文字，并将诊断审核和微练习审核明确分成两个时间段。
- 现有盲审页增加“首次审核前阅读启动说明”入口；新增Markdown交接备份。
- 增加静态回归，锁定九项关键交接信息和盲审入口。

## After

- 自动化测试由128项增至129项并全部通过。
- 浏览器无指导检查可从页面直接理解审核目的、范围、顺序、时间、隐私、暂停方式、冲突行为、数据门槛和下一步入口。
- 桌面视觉检查显示主标题、CTA、四项范围摘要和后续协议层级清晰，没有引入额外交互依赖。
- 12条合成框架评测保持100%；Teacher Gold和真实教师练习有效率继续保持N/A。

## Regression

- 未修改五类一级错因、审核协议、Gold准入门槛或已有审核记录。
- 20–30分钟仅作为10条试审的计划估计，不作为实际观察结果或绩效要求。
- 启动页不会替老师提交判断，也不计入教师样本。
