# Iteration 034 — 真实用户研究会话去重

## Before

- 研究记录只拒绝重复`participant_id`，不拒绝重复`research_session_id`。
- 同一条产品事件链理论上可以更换参与者编号后重复保存，并被计入5名最低样本门槛。
- 历史或手工导入到浏览器存储的重复会话仍可能进入聚合指标。

## Change

- 新增研究记录时同时校验参与者编号和匿名产品会话的唯一性。
- 同一`research_session_id`再次保存时拒绝，并明确提示必须为每名参与者创建新的专属会话。
- 汇总前统计结构有效记录中的会话次数；任何发生复用的会话对应记录全部排除，不任意保留其中一条。
- 研究状态面板新增“重复会话记录（已排除）”，导出汇总同时记录结构有效数与冲突数。
- 增加用同一事件链伪装两名参与者、再填充到样本门槛的永久回归。

## After

- 自动化测试由129项增至130项并全部通过。
- 5条结构有效记录中若有2条复用同一会话，合格记录只剩3条，聚合指标保持N/A。
- 浏览器研究页在0真实样本时显示：合格记录0、重复会话0、全部比例与中位数N/A。
- 12条合成框架评测保持100%；未新增或伪造真实用户记录。

## Regression

- 合法的不同参与者、不同匿名会话路径不变。
- 纠错仍禁止更换研究会话；撤回和最小审计行为不变。
- 重复会话记录被排除但不由系统静默删除，便于发现和纠正研究操作问题。
