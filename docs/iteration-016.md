# Iteration 016: Blind Review Pilot Checkpoint

## Before

- 50条候选按作者拟议类别分组排列，连续审核同类候选可能形成节奏和类别预期偏差。
- 审核者必须直接面对50条，没有在正式批量审核前检查样本可审性的低成本节点。
- 拒绝或标记需修订时可以不写原因，导致样本问题难以转化为可执行修复。

## Change

- 前10条采用固定交错顺序，五类候选各一条后再重复一轮；浏览器仍不接收作者类别或模型预测。
- 新增10条试审检查点，只显示已处理数、样本问题数和检查点状态。
- 试审阶段禁止显示模型标签、置信度或一致率，避免影响剩余40条判断。
- 拒绝或需修订必须填写具体说明，客户端与服务端双重校验。
- 案例页实时显示交错试审进度，但50条官方门槛保持不变。

## After

- 审核启动任务从单次50条变为先完成10条交错试审。
- 试审处理、问题记录和可检查状态均可实时计算。
- 非批准样本必定留下可用于修订的原因。
- 模型结果仍保持盲态，试审不会生成非官方一致率。

## Regression

- 72项自动化测试通过。
- Teacher Gold准入、冻结预测完整性和50条官方门槛没有变化。

## Remaining Risk

- 当前试审记录仍为0/10，流程改善不等于已经取得独立教师标签。
- 单一审核者可能存在稳定判断偏差；正式结果最好增加第二位教师复核边界争议案例。
