## 最大的五个Gap

1. **Future Improvement — 正式Teacher Gold尚未达到50条。** 当前仅可报告10条独立教师探索性试审；正式一致率、Macro F1和置信度校准保持N/A，不阻塞作品集交付。
2. **P0 — 真实语义Provider尚未达到晋级证据门槛。** DeepSeek v3真实评测在8条作者边界集上7/8正确、0条不安全，剩余1条`over_inference`案例被契约闸门安全拒绝；输出契约失败率由v2的25%降至12.5%，但仍未达到0。样本也不是独立教师Gold，学生产品继续使用规则Provider。
3. **Future Improvement — 正式分类与校准指标仍不可计算。** 50条候选中只有10条独立教师Gold；当前12条框架集和8条困难边界标签均为项目作者标签。
4. **已闭环 — 微练习教师复核。** 10/10审核完成，8/10通过；两条失败集中在相邻错因边界，作为后续taxonomy判定规则优化输入。
5. **已闭环 — 修复后用户复测。** 3名新目标用户均通过具体错点、下一步动作和练习针对性检查；仅作探索性可用性结论，不推断提分或长期迁移。

## 第一轮优先级

先建立可重复运行的eval harness与确定性安全底座。原因：没有baseline时增加LLM、页面或Agent功能无法判断质量是否改善。

## 数据声明

首批评测样本为项目生成的IELTS-style短文与合成学生错误。它们用于验证框架，不代表真实用户表现，也不是教师原创或复核样本，不作为最终教师一致率证据。正式MVP需要扩展到至少50条教师复核样本。
