# 招聘者3–5分钟案例理解测试

## 研究问题

首次接触Reading Lens案例的招聘相关评审者，能否在3–5分钟阅读后，不查看案例、不接受提示，复述作品集必须传达的九项内容。

这项测试验证案例表达是否清楚，不验证Offer结果、模型质量或学习效果。

## 样本准入

- 产品招聘人员、产品面试官/产品负责人或AI教育从业者；
- 此前未看过该案例；
- 同意匿名记录并知道可以停止或撤回；
- 使用匿名编号，不记录姓名、电话、邮箱、公司或学校；
- 复述时关闭案例和笔记；
- 主持人不提供内容提示。

少于5名合格记录时，所有聚合指标保持N/A。

## 操作流程

1. 打开`http://localhost:4173/portfolio-review.html`。
2. 填写匿名编号、角色并确认首次接触和同意。
3. 点击“开始阅读案例”，让评审者独立阅读；主持人不解释。
4. 在3–5分钟内结束阅读，关闭案例页。
5. 只说：“请用自己的话介绍这个项目，以及你认为它如何工作、如何验证、目前哪里还不可靠。”
6. 根据自由复述逐项记录九项标准；不要朗读标准或追问遗漏项。
7. 保存后检查样本门槛；导出匿名JSON作为作品集研究证据。

## 九项标准

1. 用户问题：学生知道做错，却不知道最早错在哪一步。
2. 普通答案解析为什么不足。
3. 为什么需要Evidence和Reasoning。
4. 固定五类错因及最早失败步骤。
5. 确定性验证到Learner State的完整工作流。
6. 教师Gold、分类、校准和边界评测。
7. 当前规则基线的高拒答与真实语义证据缺口。
8. 证据、结构输出和低置信复核兜底。
9. 用迁移、复发和真实行为验证学习，而非小样本提分。

## 指标解释

- `within_three_to_five_minutes_rate`：阅读用时180–300秒的比例。
- `all_nine_recall_rate`：九项均由评审者自主复述的比例。
- `eight_or_more_recall_rate`：自主复述至少八项的比例。
- `concept_recall_rates`：每个概念的独立召回率，用于定位案例页表达弱点。

5名样本只能作为探索性案例理解证据。不要把理解率写成招聘成功率，也不要根据测试结果自动改写模型或学习效果结论。

## 撤回

评审者要求撤回时，在记录旁点击“撤回”，填写至少3个字符的原因后明确确认。系统只移除指定记录；审计仅保留匿名编号、原因和时间，不保留复述内容或概念评分。
