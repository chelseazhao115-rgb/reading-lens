# Iteration 041 — 双轨审核编号与浏览器身份隔离

## Before

- 作者QA和独立教师Gold虽然已分开存储，但页面仍共用`reading-lens-reviewer-id`本地缓存。
- 同一浏览器切换轨道时，`author-001`可能被自动带入独立教师页面，或独立教师编号被带入作者页面。
- 服务端只拒绝测试编号，没有强制轨道专属格式；用户误勾独立性声明时，项目作者编号可能进入Gold审计字段。

## Change

- 作者QA编号强制使用`author-`前缀，独立教师编号强制使用`teacher-`前缀。
- 服务端在两个保存入口分别校验编号命名空间，跨轨道编号失败关闭。
- 浏览器改用两个独立缓存键，不再读取旧的共享编号。
- 两个页面提供不同占位符和可执行错误提示。
- 新增跨轨道提交回归测试与前端静态约束。

## After

- 自动化测试由143项增至144项并全部通过。
- 浏览器同一配置文件实测：作者页编号为空、提示`author-001`；独立页编号为空、提示`teacher-027`；旧`browser-validation`不再自动带入。
- `author-001`提交独立Gold与`teacher-001`提交作者QA均被服务端拒绝。
- 作者QA、独立试审和Teacher Gold真实数量继续保持0，没有模拟提交污染。

## Regression

- 教师资质、独立性声明、协议版本、标签↔最早失败步骤和专业依据门槛保持不变。
- 历史测试记录仍保留并隔离；旧共享浏览器编号不删除，但新版页面不再读取。
- 正式教师指标继续保持N/A。
