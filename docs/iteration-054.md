# Iteration 054 — 真实研究JSON可安全恢复

## Before

- 研究工具可以导出JSON，但无法导入；更换浏览器或localStorage丢失后，首轮与第二轮数据会割裂。
- 手工复制数据可能造成重复会话、覆盖纠错版本或信任旧summary。

## Change

- 新增Schema v2/v3导入，逐条重新执行目标用户、同意、遥测、耗时、匿名字段和研究轮次校验。
- 导入重新计算全部汇总，不信任文件中的旧summary。
- 采用原子式只追加：完全相同的记录跳过；参与者编号或研究会话冲突但内容不同则整批拒绝，现有数据不改变。
- 导入文件内部的重复参与者或重复会话直接拒绝；最多500条。
- 不导入来源文件中的审计内容；只为本次新增记录写入最小`imported`审计事件。
- 研究页增加本地JSON选择入口和明确的新增、跳过、失败提示。

## After

- 167/167项自动化测试通过。
- 使用真实首轮v2导出回放：5条全部通过、导入5条、重复0、总体指标保持100%无帮助完成、100%证据成功、80%诊断理解、中位59秒与302秒。
- 浏览器确认导入入口、“只追加不覆盖”说明和第二轮复测标识同时可见。

## Regression

- 导入只发生在用户主动选择本地文件后；本轮没有替用户上传或改变现有浏览器研究记录。
- 冲突导入不会产生部分写入，也不会用文件summary覆盖重新计算结果。
