# Iteration 021 — 微练习两阶段盲审

## Before

- 教师审核页在判断前直接展示目标错因和标准答案。
- `targets_primary_error`、`unique_answer`、`answer_correct` 容易受到提示偏差。
- 只有六维勾选结果，无法验证教师能否在无提示条件下独立答对或识别训练目标。

## Change

- 第一阶段只展示原文、题目和选项，教师独立提交 `blind_answer` 与 `blind_target_error`。
- 服务端在盲判锁定前从响应中删除 `answer` 与 `target_error`，避免只靠前端隐藏。
- 盲判提交后写入服务器时间并禁止覆盖；最终审核必须由同一审核者完成。
- 第二阶段才揭示标准答案和目标错因，随后进行原有六维审核。
- 盲答或盲判错因不一致时不得批准，必须标记相应维度不通过并说明。
- 新增盲答一致率和盲判错因一致率；10题未全部完成前保持 `null`。

## After

- 微练习教师评测从“看答案后确认”升级为可审计的先盲判、后复核流程。
- 待审核数据仍为0/10，不生成教师有效率或盲审一致率结论。
- 自动化回归由89项增加到93项，全部通过。

## Regression

- 原有10道练习内容、答案和目标错因未修改。
- 即时练习、Retry、Transfer学习闭环未修改。
- CSV保留为审计/导入载体，但因包含Gold而明确不得宣称为盲审。
