# Iteration 053 — 作品集稳定展示真实5人证据

## Before

- 案例页从当前浏览器localStorage读取用户研究；招聘者在新浏览器打开时会把已完成的5人测试显示为0/5。
- 状态文案把“教师Gold不足”和“真实用户不足”混为一谈。
- 内嵌产品与普通Demo共用状态，可能展示开发者上一次遗留的答案或诊断。

## Change

- 从首轮原始导出生成脱敏聚合Artifact，只保存样本数、比例、中位数、源文件SHA-256、已知缺陷说明和结论边界；不包含参与者编号、研究会话ID、观察笔记或原始记录。
- 新增Artifact验证器，校验比例与分子分母一致、5个唯一会话、SHA-256格式、限制说明和禁止字段。
- 新增只读`/api/usability-summary`，案例页由服务端证据Artifact展示5人结果，不再依赖访问者localStorage。
- 案例页明确区分：首轮可用性已达到探索性门槛；教师Gold不足，所以模型官方指标仍为N/A。
- 内嵌产品使用独立预览命名空间并在案例页载入时清空，不继承普通Demo状态。

## After

- 164/164项自动化测试通过；12条合成框架评测保持100%。
- API返回5名合格目标用户、5个唯一会话、无帮助完成100%、证据选择100%、诊断理解80%、核心路径中位59秒和P004限制说明。
- 空白浏览器运行态验证：案例页稳定显示5/5及限制；内嵌产品从第1题空白状态开始，不再出现旧诊断残留。

## Regression

- 原始参与者级JSON仍只保存在用户本地；作品集Artifact不复制观察笔记或会话标识。
- 5人结果仍只称为探索性可用性证据，不宣称提分、长期学习或总体人群效果。
