# Iteration 035 — 无指导用户测试交接页

## Before

- 研究记录页包含主持步骤，但没有独立的测试前交接入口。
- 首次主持人可能把操作说明展示给参与者、使用额外引导，或把localhost专属链接发到另一台设备后误以为事件能同步回来。
- 参与招募话术、失败样本保留规则和远程测试边界仅存在于内部指南。

## Change

- 新增`/usability-start.html`，明确这是主持人页面，参与者只看产品页。
- 固定唯一开场话术和诊断复述话术，并明确不得提醒划选证据、填写思路、点击练习或完成迁移。
- 增加目标用户、匿名同意、1人1会话和测试前环境检查。
- 明确当前localStorage架构必须使用同一浏览器配置文件；远程测试只能共享或控制同一测试浏览器。
- 明确卡住、求助、放弃和技术故障都要保存，提供帮助后必须记录为非无指导完成。
- 提供可直接发送的参与邀请与Markdown启动包；研究记录页增加启动说明入口。

## After

- 自动化测试由130项增至131项并全部通过。
- 浏览器无指导检查能找到主持人/参与者分离、固定话术、同浏览器限制、失败保留、1人1会话和非提分结论。
- 桌面视觉层级与教师审核交接页一致，主持人可直接进入研究记录工具。
- 12条合成框架评测保持100%；真实用户记录仍为0，不将页面验证计为参与者证据。

## Regression

- 参与者产品页没有新增教学步骤，不会因交接页降低真实首次使用难度。
- 研究事件、计时、样本去重、纠错和撤回逻辑不变。
- 15–25分钟是招募计划估计，不是当前用户实测结果。
