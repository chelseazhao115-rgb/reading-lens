# Iteration 024 — 诊断盲审协议冻结

## Before

- 合格教师审核可以提交一级错因标签，但无法证明教师沿固定因果链找到了“最早失败步骤”。
- approved记录可以没有专业判断依据，难以在作品集或争议复核中审计。
- 旧版审核记录已经因来源问题排除，但仍需确保旧客户端无法绕过新要求。

## Change

- 将正式诊断审核协议冻结为`diagnostic-causal-blind-v3`。
- approved记录必须同时提交教师一级标签、与标签一一对应的最早失败步骤，以及至少8字符的判断依据。
- 五类错因固定映射到证据定位、语义映射、句子理解、题型规则、推理边界；三个特殊状态映射为`not_applicable`。
- 旧协议客户端、标签与步骤不一致、依据过短的提交均由服务端拒绝。
- 未准入历史记录继续保留在审计数据中，但公开重审接口隐藏其标签、步骤、说明和审核者信息，避免锚定。

## After

- 50条审核候选包结构验证通过，CSV和JSON均包含`reviewer_failed_step`。
- 24条历史approved记录仍被隔离，正式Teacher Gold保持0，官方Accuracy、Macro F1、混淆矩阵继续为N/A。
- 103/103自动化测试通过；新增回归覆盖标签—步骤不一致和无充分依据的拒绝路径。

## Regression

- 未删除或重写任何历史审核记录。
- 审核者仍看不到模型预测、拟议标签和置信度。
- 合成框架基线、困难边界集与Teacher Gold继续分开展示。
