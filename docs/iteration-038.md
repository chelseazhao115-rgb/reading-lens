# Iteration 038 — Teacher Gold冻结预测生命周期

## Before

- Teacher审核记录中的预测本应是审核开始时的冻结快照，但完整性校验把它与“当前规则引擎重新计算的结果”比较。
- 第037轮新增用户证据闸门后，当前引擎对一条历史案例从确定诊断改为证据拒绝；历史合法快照因此被误判为篡改。
- Eval报告显示预测完整性失败，服务端启动时也会放弃整个历史审核文件并回退到空白种子，导致24条流程审核无法用于来源审计。

## Change

- 将`evals/review-pack.json`确立为当前50条候选的不可变冻结预测包。
- 服务端读取、CSV导入和Eval统一对冻结包校验，不再对当前模型重新计算的预测做相等比较。
- 新增冻结包结构与预测字段完整性验证：标签、置信度、状态、教师复核标记、Provider、Prompt版本和模型版本缺失时继续失败关闭。
- `npm run eval:review-pack`在冻结包存在时只复用它并重建盲审CSV，不覆盖已启动审核的预测版本。
- 新增模型行为变化回归：当前引擎输出可变化，但历史冻结预测仍保持完整、可审计。

## After

- 自动化测试由139项增至140项并全部通过。
- 预测快照完整性由失败恢复为通过，错误数0。
- 服务端保留50条记录及24条历史流程审核；24条全部显示为`provenance_excluded`，正式`gold_eligible`仍为0。
- Teacher官方指标继续保持不可用：Accuracy、Macro F1、混淆矩阵与confidence calibration均为null，原因是未达到50条v3教师Gold，而非技术管道损坏。

## Regression

- 修改或删除冻结预测字段仍会被完整性校验拒绝。
- 新模型不能静默重写旧预测；未来比较新模型时应建立新的版本化候选快照或独立Provider benchmark。
- 12条合成框架基线、8条困难边界和练习闭环无回退。
- 外部P0不变：教师Gold 0/50、练习教师审核0/10、真实目标用户不足5、真实语义Provider尚未获批接入。
