# Iteration 027 — 招聘者案例理解验证

## Before

- 案例页覆盖作品集要求的九项内容，但“招聘者能在3–5分钟理解”只有设计意图，没有可重复研究协议。
- 没有匿名样本准入、限时阅读、盲回忆、概念级结果或不足样本时的N/A闸门。

## Change

- 新增案例理解测试台，以5分钟证据时钟组织阅读和盲回忆流程。
- 固定九项作品集理解标准；主持人必须对每项显式记录“自主提到/没有提到”。
- 样本必须是首次接触、招聘相关角色、匿名同意、关闭案例后复述且未经提示。
- 少于5名合格样本时聚合指标保持N/A；达到门槛后报告时间窗口、九项全召回、八项以上和概念级召回率。
- 支持匿名JSON导出和指定记录撤回，审计不保留复述或概念评分。
- 案例页证据区动态显示案例理解测试进度。

## After

- 测试页初始显示0/5以及全部指标N/A。
- 浏览器实测开始阅读、案例打开、结束计时、盲回忆解锁均可运行，未保存测试生成的伪造样本。
- 页面控制台错误为0。
- 自动化测试由110项增至117项并全部通过。

## Regression

- 不把主持人勾选、自评或不足5人的数据称为理解效果。
- 不采集直接身份信息，不修改已有真实用户、教师审核或产品事件数据。
- 未修改核心用户、五类错因、模型指标或学习流程。
