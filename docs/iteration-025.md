# Iteration 025 — 核心学习闭环刷新恢复

## Before

- Learner State会保留累计结果，但刷新页面会丢失当前答案、证据、推理、诊断结果和正在进行的练习。
- 刷新后用户只能重新提交，既破坏学习闭环，也可能重复写入诊断和练习漏斗。

## Change

- 增加`reading-lens-workflow-v1`版本化草稿，独立于累计Learner State保存当前工作流。
- 持久化答案、证据、推理、诊断输出、当前练习、尝试次数、提示次数、反馈和待进入的迁移题。
- 恢复采用只读渲染，不重复记录`question_started`、`diagnosis_completed`、`micro_exercise_started`或`transfer_started`。
- 损坏或未知版本草稿安全回退为空状态；清除演示数据时只删除本产品的Learner State与Workflow键。

## After

- 浏览器实测刷新后仍显示原答案、证据、推理、证据有效状态、定位错误诊断和即时练习。
- 即时练习正确后刷新，仍显示“进入迁移题”；进入迁移题后再次刷新，仍可继续提交。
- 连续刷新后诊断计数保持1、微练习计数保持1，控制台无错误。
- 自动化测试由103项增至106项并全部通过。

## Regression

- 教师Gold、评测数据和历史审核记录均未修改。
- 未改变五类错因、核心用户或学习流程。
- 工作流草稿仅保存在当前浏览器，不宣称跨设备恢复。
