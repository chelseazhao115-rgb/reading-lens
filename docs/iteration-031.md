# Iteration 031 — 终态诊断防重复提交

## Before

- 同一道题获得`diagnosed`、`correct`或`abstained`结果后，提交按钮会在请求结束时重新启用。
- 用户可以重复提交同一份答案、证据和推理，重复写入`diagnosis_completed`并放大诊断次数、复发错因和漏斗数据。
- 刷新恢复虽不会自动重复埋点，但恢复后的表单仍可再次提交。

## Change

- 将`diagnosed`、`correct`和`abstained`定义为终态；证据校验失败与服务错误保留修正和重试能力。
- 终态后锁定答案、证据、推理、取证按钮和提交按钮，并增加程序化提交守卫。
- 刷新恢复终态工作流时继续锁定；只有点击“开始下一次诊断”并切换题目后才解锁。
- 增加终态判定单元测试，避免后续新增状态时误伤重试路径。

## After

- 浏览器实测终态后5个表单控件、取证按钮和提交按钮全部禁用，按钮文案为“本轮诊断已完成”。
- 刷新后仍停留在同一题和同一结果，全部输入继续锁定且不产生新事件。
- 点击“开始下一次诊断”后进入第2/5题，结果区隐藏，全部输入与取证按钮恢复可用。
- 自动化测试由125项增至126项并全部通过；12条合成框架评测保持100%，其教师Gold限制不变。

## Regression

- `evidence_validation_failed`与请求异常不是终态，用户仍可修改证据后重试。
- 练习、迁移和下一诊断门槛未改变。
- 未将本地浏览器验证计入真实用户、教师Gold或作品集理解度样本。
