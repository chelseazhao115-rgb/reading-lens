# Reading Lens Chrome 插件

当前开发版覆盖爱听写 IELTS 页面，但只有通过严格做题页或结果页结构识别后才激活：

`https://www.idictation.cn/ielts/*`

## 本地安装

1. 在项目根目录运行 `npm start`，保持本机诊断服务监听 `127.0.0.1:4173`。
2. 打开 Chrome 的 `chrome://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，加载项目中的 `extension` 目录。
4. 打开爱听写阅读做题页。答案会在本地自动保存；划选原文可添加三类高亮、Note或错词。
5. 进入结果页后，可点击某题旁的“AI 错因诊断”。

扩展不会直接调用模型，不包含 API Key，也不会保存完整文章。工作区只保存答案、选中文字、前后文锚点、Note、内容哈希和学习摘要。重新打开同一套题时必须由学生确认才会回填，且不会自动提交。

错词加入后会请求本机 `/api/vocabulary/enrich` 生成语境释义。未配置 `DEEPSEEK_API_KEY`、服务不可用或输出未通过契约时，词条仍会保留并允许手工编辑。错词本可按状态筛选并生成 A4 打印页，再通过 Chrome 打印窗口另存 PDF。

侧栏支持导出和导入版本化 JSON 备份、删除当前试卷记录与清空全部本地学习数据。数据仅保存在当前浏览器，不进行账户或跨设备同步。

## DOM 适配边界

适配器版本为 `idictation-v2`。除显式语义标记外，也支持真实结果页的独立单选框题组和左右分栏文章结构。每个必需字段必须可靠识别；题号、题型、题干、学生答案、正确答案、文章或标准证据缺失时停止诊断。标准证据还必须逐字存在于文章中。

若线上页面结构与当前 fixture 不同，可在目标页向内容脚本发送 `READING_LENS_ADAPTER_DEBUG` 消息。响应只包含选择器命中数量，不包含正文、答案或证据内容。确认真实 DOM 后再更新 `extension/idictation-adapter.js` 与 `test/fixtures/idictation-result.html`，不要加入整页文本兜底。
