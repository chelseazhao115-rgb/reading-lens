# Iteration 036 — 迁移题断网恢复与响应契约

## Before

- 迁移题提交后若断网或接口失败，`finally`逻辑会让按钮永久保持禁用，核心闭环无法继续。
- 请求发出前已增加练习尝试次数；网络失败也会被误记为学生多试了一次。
- 客户端不检查HTTP状态或练习结果结构，非2xx或畸形200响应可能被写入Learner State并错误解锁路径。

## Change

- 练习判分响应必须同时通过HTTP成功和客户端结构契约：匹配练习ID、合法错因、阶段、布尔判分与反馈。
- 即时练习答对时，随响应返回的下一题必须是同一错因的合法迁移题，且不得携带答案键。
- 断网、非2xx、无效JSON或畸形响应统一进入失败恢复：撤销本次未核验尝试、恢复原按钮文字并重新启用。
- 只有服务端确认的练习结果才能写入尝试次数、练习结果、迁移事件和下一诊断门槛。
- 增加响应契约和未核验尝试回滚单元测试，并把关键恢复逻辑加入静态回归。

## After

- 自动化测试由131项增至133项并全部通过。
- 浏览器断网实测：迁移题失败后显示“练习核验暂时不可用”，按钮恢复为“提交迁移题答案”，下一诊断保持锁定。
- 服务重启后原答案可再次提交；成功后按钮显示“迁移题完成”、迁移率100%、下一诊断解锁。
- 断网请求不消耗学生尝试次数；不完整、错ID、错类别或泄露答案的下一题响应被拒绝。
- 12条合成框架评测保持100%。

## Regression

- 即时练习答错后的Retry、答对后的迁移入口和迁移题成功/失败记录逻辑不变。
- 服务端答案键零泄漏规则继续生效。
- 断网浏览器会话使用研究测试编号，不计入真实用户研究数据。
