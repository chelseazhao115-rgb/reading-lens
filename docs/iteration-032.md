# Iteration 032 — 教师审核并发覆盖保护

## Before

- 诊断与微练习审核页面会读取共享审核文件，但提交时不携带样本版本。
- 两位老师同时打开同一条样本后，较晚提交的旧页面可能覆盖较早保存的新判断。
- 被覆盖的审核者、标签、盲判阶段和服务器时间会破坏Teacher Gold来源审计。

## Change

- 为诊断案例和微练习案例生成服务端24位审核版本令牌；令牌只表达记录版本，不暴露模型Gold。
- 浏览器在诊断保存、微练习盲判揭示和六维审核保存时回传读取时的版本。
- 服务端在任何标签、资质或状态处理前执行乐观并发校验；旧版本统一返回`409 stale_review_revision`。
- 页面收到冲突后重新加载服务端最新记录，并用中文提示审核者检查最新状态。
- 增加诊断和微练习两条并发覆盖回归。

## After

- 自动化测试由126项增至128项并全部通过。
- 运行中API为两类案例下发24位版本令牌；使用旧令牌提交时，两条接口均返回409且不写入审核数据。
- 同一条记录的盲判揭示、教师结论或审核者来源发生变化后，旧页面不能再覆盖它。
- 12条合成框架评测仍为100%；Teacher Gold仍为0/50，微练习教师审核仍为0/10。

## Regression

- 单一审核者正常连续审核路径不变，成功保存后客户端自动接收新版本令牌。
- 模型预测、拟议标签和置信度仍不发送给盲审页面。
- 未修改、删除或伪造任何已有教师审核记录。
