# Iteration 030 — 微练习答案键零泄漏

## Before

- 初始练习题公开对象不含答案，但`POST /api/exercise/check`的每次响应都包含`correct_answer`。
- 学生第一次答错后，可以从网络响应直接读取唯一答案，破坏Retry与Transfer作为学习证据的有效性。
- 既有“首轮隐藏答案”证据只覆盖首次题目载荷，没有覆盖判分响应。

## Change

- 增加练习判分结果的安全公开投影；内部结果保留答案用于确定性判分，HTTP结果永久移除答案键。
- 答错即时练习、答对即时练习、迁移题作答和随答对响应返回的下一题对象均执行泄漏回归。
- 下一题仍公开所有可选项，但不标记哪一个是正确选项。

## After

- 答错响应字段仅包含判分、阶段、反馈和`next_exercise=null`，答案键泄漏为0。
- 答对响应的顶层和下一题对象均无`answer`或`correct_answer`字段；下一题只包含ID、错因、阶段、材料、问题、选项和来源。
- 迁移题判分响应答案键泄漏为0。
- 浏览器实测首次答错进入Retry且不能开始下一诊断；答对后只解锁迁移题，控制台错误为0。
- 自动化测试由123项增至125项并全部通过。

## Regression

- 内部唯一答案仍保留，确定性判分能力未降低。
- 学生可见选项不被删减，只有答案标识被隐藏。
- 未改变练习内容、错因体系、提示策略或迁移门槛。
