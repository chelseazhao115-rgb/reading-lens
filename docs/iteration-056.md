# Iteration 056 — 修复后复测入口完整性

## Before

- `/usability.html`已经支持`post_fix_retest`和三项教学价值复述编码，但页面仍以“首次用户测试”命名，容易与第二轮复测混淆。
- `#open-research-session`虽带`hidden`属性，通用`.inline-button { display: inline-block; }`却覆盖了浏览器默认隐藏样式。
- 主持人在尚未创建匿名会话时就能看到并打开普通`/`产品页；这条路径没有`research_session`参数，可能造成事件链无法归属并污染复测。

## Change

- 增加全局`[hidden] { display: none !important; }`，保证带`hidden`属性的交互控件不能被组件展示样式意外恢复。
- 将研究页标题改为“真实用户无指导可用性测试”，浏览器标题改为“真实用户复测记录”，不再把第二轮工具误称为首次测试。
- 在现有服务端静态资源回归中加入：参与者入口必须初始带`hidden`，且全局隐藏规则必须存在。

## After

- 169/169项自动化测试通过。
- 浏览器验证：未创建会话时参与者入口和同步按钮均不可见。
- 填写临时匿名编号并确认同意、创建会话后，两个操作才显示；参与者链接包含唯一`research_session`参数。
- 临时验证没有提交表单、没有写入真实用户记录。

## Regression

- 本轮不改变研究记录Schema、首轮5人Artifact或指标计算。
- 不新增任何用户证据；修复后真实复测仍为0/3。
