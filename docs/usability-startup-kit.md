# 首次用户测试启动包

## 参与邀请

你好，我正在测试一个面向雅思阅读5.5–6.5分学习者的错因诊断原型，想了解第一次使用时哪些地方清楚、哪些地方会卡住。任务约需15–25分钟，不测试你的能力，也不会要求姓名、手机号、微信、邮箱或学校信息。过程只使用匿名编号，你可以拒绝参与或随时停止；本次测试不用于证明提分。如果你愿意，我会安排一个使用同一测试浏览器的现场或远程屏幕共享时段。

## 执行入口

1. 主持人先阅读`http://localhost:4173/usability-start.html`。
2. 在`http://localhost:4173/usability.html`确认准入、同意和匿名编号。
3. 每名参与者创建新的专属产品会话。
4. 从记录页点击“打开参与者产品页”，保持在同一浏览器配置文件中。
5. 使用固定主持话术，不解释按钮、证据、答案或练习顺序。
6. 完成或卡住后返回记录页同步事件并保存。

## 固定话术

> 请独立完成一次阅读错因诊断和系统提供的后续练习。请按照你自己的理解操作，我现在不会解释页面或告诉你答案。如果你无法继续，可以直接说出来。

结果出现后：

> 请用自己的话说明：你错在哪里、为什么会错、下次准备怎么做。

## 当前技术边界

研究事件保存在参与者使用的浏览器本地存储。不能把localhost链接直接发到另一台设备后，期待主持人记录页自动收到事件。远程测试必须共享或控制同一个测试浏览器；否则不能将该记录标记为事件链已验证。

卡住、求助、放弃、拒答和技术故障都应保存。若提供任何操作帮助，`unassisted_completion`必须为`false`。
