# Iteration 028 — 可重复诊断与最小题集轮换

## Before

- 产品只有一道固定演示题，没有完成闭环后开始下一次诊断的正式入口。
- 用户只能重复提交同一道题，`question_started`不会为新一轮正确记录。
- Recurring Error Rate和7-Day Repeat Usage虽然有计算代码，却缺少真实产品路径产生多轮行为。

## Change

- 建立5道项目原创TRUE/FALSE/NOT GIVEN最小题集，全部通过标准证据原文包含校验。
- 按固定顺序轮换题目，不随机挑题，保证测试可复现；第五题后回到第一题。
- 错因诊断必须完成即时练习与迁移题后才解锁“开始下一次诊断”。
- 正确路径和安全拒答路径在诊断终态解锁下一轮。
- 新一轮重置答案、证据、推理、诊断和练习，但保留Learner State并记录新的`question_started`。
- 工作流草稿升级到Schema v2，保存`question_id`和`path_completed`；Schema v1自动迁移且保留表单与诊断。

## After

- 浏览器实测第一轮定位错误诊断后，练习前下一轮按钮不可见；迁移题完成后可见。
- 点击后显示`QUESTION 2 OF 5`与新材料，结果区隐藏，已记录诊断保持1。
- 刷新后仍停留在第二题且Learner State不丢失。
- 第二题正确路径完成后也可继续下一诊断。
- 浏览器控制台错误为0。
- 自动化测试由117项增至120项并全部通过。

## Regression

- 未建立完整题库、自适应系统或新题型。
- 五道内容全部标记为项目原创，不使用未经授权雅思真题。
- 未清除旧草稿或累计学习记录，旧Schema自动迁移。
- 未改变五类错因、核心用户或证据优先流程。
