# Iteration 052 — 五类错因都有证据级具体反馈

## Before

- P005反馈改进只覆盖`paraphrase`；定位、句子理解、题型策略和推理越界仍只有通用Where/Why/Fix。
- 第二轮用户若遇到其他错因，仍可能得到“分类正确但教学价值不足”的体验。

## Change

- 复用每道原创题服务端已有、且能在题干和原文逐字验证的作者语义对应；没有让模型自由生成quote或具体对应。
- 为五类错因分别生成不同动作：寻找决定性证据、核对同义对应、标记句法逻辑词、映射TRUE/FALSE/NOT GIVEN规则、删除无原文依据的推断。
- 每题增加服务端`answer_rule`，由权威正确答案确定题型规则解释；公开题目接口继续移除全部诊断支持元数据。
- 通用区块标题由“具体漏掉了什么”改为“具体要核对什么”，避免把题型策略等错因错误描述为漏掉同义替换。

## After

- 162/162项自动化测试通过；12条合成框架评测保持100%，无安全回退。
- 浏览器使用“正确答案但错误规则”的题型策略案例验证：页面展示权威题干/原文对应、FALSE的信息状态规则和立即动作，并正常生成题型策略微练习。
- 浏览器确认最终中性标题已生效。

## Regression

- 具体反馈只能来自服务端作者标注；公开题目不泄露正确答案、标准证据、语义对应或题型规则。
- 这证明功能和渲染覆盖五类，不证明教学价值已经提高；仍需第二轮真实用户复测。
