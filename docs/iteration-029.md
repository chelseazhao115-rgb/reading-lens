# Iteration 029 — 服务端权威题目与Gold防篡改

## Before

- 浏览器在诊断请求中提交`passage`、`question`、`correct_answer`和`standard_evidence`。
- 服务端直接使用客户端值；被篡改或版本过期的客户端可以改变正确答案与标准证据，污染诊断、证据验证和产品指标。
- 未知题目ID没有独立拒绝边界。

## Change

- 将5道题的完整真值移入服务端`src/demo-questions.js`。
- 新增公开题目接口，只返回ID、标题、原文、题干、题型和内容来源，不返回正确答案或标准证据。
- 前端只提交`question_id`、学生答案、学生证据、判断过程和可观察历史错因。
- 服务端按`question_id`重建完整诊断输入，只允许白名单学生行为字段进入诊断链。
- 未知题目ID返回HTTP 400，不回退到第一题。
- 标准证据只在诊断完成后由服务端返回；旧草稿仍可兼容显示原有结果。

## After

- 公开接口返回5题，`correct_answer`和`standard_evidence`泄漏数均为0。
- 未知题目ID运行时返回HTTP 400和`unknown_question_id`。
- 客户端同时伪造正确答案、原文、题干和标准证据后，结果仍按服务端真值返回`status=correct`、`answer_result=correct`，伪造证据未进入响应。
- 浏览器真实诊断仍显示正确的服务端标准证据，控制台错误为0。
- 自动化测试由120项增至123项并全部通过。

## Regression

- 未改变五类错因、因果链、置信策略或练习流程。
- 多轮题目轮换、Schema迁移和研究会话隔离保持可用。
- 题目内容来源仍为项目原创，不使用未经授权雅思真题。
