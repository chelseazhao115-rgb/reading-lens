# 用户 PDF 导入

入口：`http://localhost:4173/import.html`

该入口用于导入用户合法持有的 IELTS 阅读 PDF，而不是建设、抓取或分发真题库。

## 使用流程

1. 上传文字版或扫描版 PDF，文件不得超过 60MB 或 200 页；缺少文字层的页面会自动执行英文 OCR。
2. 系统自动预选 Passage 页面并识别题号、题型、题干、选项和答案候选。
3. 确认构成一篇 Passage 的连续页面，校对自动识别结果，并补充逐字标准证据。
4. 开始练习。学生答案先锁定；提交当时使用的证据和真实思路后，系统才揭示结果并运行错因诊断。
5. 完成针对性微练习和迁移题。

## 数据边界

- 服务端在内存中解析上传内容，不把 PDF 写入磁盘。
- 浏览器仅用 `sessionStorage` 保存当前导入练习，关闭标签页或浏览器会话后清除。
- 长期历史只保存文档哈希、练习名称、事件类型和题号等有限元数据，不保存文章全文。
- PDF 必须由用户合法持有；产品不包含抓取、下载或公开分发第三方真题的功能。
- 扫描图片型页面使用本机 OCR；图片只在内存中渲染，处理完即释放，不写入磁盘。
- OCR 和自动题目识别结果始终是待校对候选，不会静默作为正确答案或标准证据。

## 安全失败

以下情况会停止导入或诊断，不让模型猜测缺失信息：文件类型或签名不正确、PDF 加密、正文过少、页数超限、题目字段缺失、标准证据或学生证据不能在文章中逐字匹配。
