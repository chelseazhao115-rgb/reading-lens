# Iteration 049 — 首轮5人测试的开始清晰度修正

## Before

- 5/5真实用户完成测试，但阻塞频率显示`start_clarity` 2次、证据划选1次、答案/理由输入1次。
- P003不理解为什么不能只比较答案；P001第一次不知道证据操作顺序；P002看到10字符限制后出现凑字数行为。

## Change

- 首页直接解释“相同答案可能来自不同思路”，说明答案、证据和理由各自的诊断作用。
- 进度改为四个明确步骤：作答、划选证据、一句话说明、诊断。
- 理由输入旁解释为什么必须填写，并明确“一句话即可、无需凑字数”。
- 移除HTML的10字符硬门槛；信息不足仍由现有安全拒答机制处理。

## After

- 158/158自动化测试通过。
- 浏览器实际页面确认显示四步顺序、理由用途说明与“无需凑字数，一句话即可”。
- 真实可用性改善仍需要下一批用户或修复后补测证明，不能由文案上线直接推断。

## Regression

- 证据仍必须来自原文；理由仍为必填；不修改五类错因和核心学习闭环。
