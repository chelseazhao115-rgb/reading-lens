# Iteration 062 — 外部教师本地访问边界

## Before

- 微练习启动页已有可复制邀请模板和`http://localhost:4173`审核入口。
- 权威监听状态实际为`127.0.0.1:4173`，另一台电脑无法访问。
- 邀请文字没有说明这一点，项目作者可能把localhost链接直接发给外部老师，造成“页面打不开”的招募失败。

## Change

- 启动页新增“不要直接发送localhost链接”的本地访问说明。
- 邀请模板改为预约同一台测试电脑的现场时段，或通过屏幕共享/远程控制该电脑完成。
- 教师审核指南和启动工具包同步记录本机边界。
- 明确未经安全与隐私决策，不把服务擅自改为局域网监听或临时公网暴露。
- 页面回归测试锁定访问边界文案。

## After

- 177/177项自动化测试通过。
- 运行时确认服务监听`127.0.0.1:4173`，与新文案一致。
- 招募时发送的是参与邀请与时间安排，不再把本地URL伪装为远程可访问链接。

## Regression

- 不改变服务监听地址、网络暴露面、审核协议或数据存储。
- 不引入第三方部署、账号、隧道或新隐私风险。
- 独立教师审核仍为0/10；本轮只消除外部交接中的错误访问假设。
