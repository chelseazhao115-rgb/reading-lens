# 教师审核启动包

## 可直接发送的邀请文字

你好，我正在验证一个“AI雅思阅读错因诊断教练”。它不是答案解析器，而是根据学生答案、证据句和思考过程判断最早发生的错误。想邀请一位具有雅思阅读教学或教研经验的老师，先独立盲审10条原创合成案例，预计20–30分钟。页面不会展示模型标签或置信度，也不要求姓名、邮箱或学生信息；完成试审后再共同判断样本是否适合继续。若你愿意参与，我会发送本地审核入口和匿名编号规则。

## 交接入口

1. 先打开`http://localhost:4173/review-start.html`阅读完整说明。
2. 使用稳定匿名编号，例如`teacher-027`；不得使用姓名、邮箱、手机号、机构或学生信息。
3. 先完成10条交错试审，预计20–30分钟；实际耗时不作为绩效要求。
4. 检查样本质量与来源准入后，再将剩余40条分2–4批完成。
5. 微练习审核另开一个时间段，先打开`http://localhost:4173/exercise-review-start.html`阅读独立性与两阶段规则，再从动态CTA进入下一题。
6. 两类审核链接均为本机localhost入口；外部老师需使用同一台测试电脑，或通过屏幕共享/远程控制该电脑操作，不能在另一台设备直接打开链接。

## 暂停、恢复与冲突

- 浏览器关闭后，服务端已保存的记录不会丢失；重新进入后从下一条未合格记录继续。
- 不要手工编辑或删除`evals/reviewed.json`与`evals/exercise-reviewed.json`。
- 若页面提示记录已被其他审核会话更新，应以重新加载后的状态为准，再次独立判断。
- 10条试审出现样本问题、来源问题或大量边界分歧时，先暂停剩余40条。

## 试审完成后的检查

- 10条是否均由声明资质的老师完成；
- 是否存在`needs_revision`或`rejected`；
- 标准证据是否为支持标准答案的最小充分证据；
- 一级标签与最早失败步骤是否一致；
- 专业说明是否引用证据和学生思路；
- 是否需要第二位老师复核相邻类别边界。

50条合格Gold不足时，Accuracy、Macro F1、校准、混淆矩阵和相邻边界结论必须保持N/A。
