# Iteration 051 — 把P005修复转化为可验证的第二轮研究

## Before

- 首轮5人可用性已经发现P005的“分类正确但没有教学价值”问题。
- 代码修复后只能证明页面提供了更具体的信息，无法证明用户真正理解了具体错点、下一步动作或练习针对性。
- 若继续沿用首轮单一“诊断理解”字段，会把修改前后样本混在一起。

## Change

- 新研究记录明确标记为`post_fix_retest`，旧记录缺少该字段时按`baseline`兼容读取。
- 第二轮增加三个结构化观察：能否复述具体错点、下一次动作、练习与错因的关系。
- 主持人只使用三个中性追问，不展示标准答案；根据用户复述编码，而不是询问“你觉得有用吗”。
- 总体可用性仍以5名为门槛；修复后教学价值以至少3名新用户为探索性门槛，并始终单独显示样本数。少于门槛保持N/A。
- 导出Schema升级为v3；旧v2的5条记录保持全部有效，且不会被计入修复后指标。

## After

- 161/161项自动化测试通过。
- 使用首轮真实导出文件回放：5/5仍结构有效、总体指标不变、`post_fix_retest_records=0`、教学价值指标为N/A。
- 浏览器确认第二轮研究页清晰显示三个观察字段、无提示主持协议、分组样本数和N/A闸门。

## Regression

- 不修改或重新解释首轮记录；新版效果必须来自新的匿名研究会话。
- 新指标仍是探索性可用性证据，不是雅思提分或长期学习效果证据。
