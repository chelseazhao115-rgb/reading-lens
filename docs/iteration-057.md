# Iteration 057 — 独立教师Gold动态续审入口

## Before

- 服务端已有10/50条合格独立教师Gold，10条试审检查点为通过且无样本问题。
- `/review-start.html`仍固定显示“先完成10条试审”和“开始独立教师试审”，无法告诉审核者试审已经完成，也不能直接定位下一条待审案例。
- 审核页本身会恢复，但启动交接文案与权威服务端进度不一致，容易造成重复劳动或误解当前阶段。

## Change

- 新增纯函数`deriveReviewHandoffState`，根据`/api/reviews`的Gold进度、试审检查点与逐条状态计算交接标题、说明、CTA和下一条案例。
- 启动页现在区分：试审进行中、试审通过可继续、试审存在问题需暂停、50条全部完成四种状态。
- API不可用时保留静态启动说明，并明确审核页仍会自动定位，不把网络失败误报为进度归零。
- 新增3项状态回归测试，覆盖第11条续审、试审问题暂停和50条完成。

## After

- 172/172项自动化测试通过。
- 权威API显示：10/50条Gold合格、10/10试审通过、0个样本问题、下一条为CASE 11。
- 浏览器启动页显示“10条试审已通过，继续完成第11–50条”，CTA为“从第11条继续”。
- 打开CTA目标后页面准确显示`CASE 11 / 50`、`10 / 50`已处理和`10`条Gold准入。

## Regression

- 未提交、修改或补写任何教师结论。
- 旧版或来源不合格审核继续被隔离，CASE 11不下发其历史标签与说明。
- Teacher Gold仍真实为10/50；本轮只消除续审流程阻塞，不提升外部证据数量。
