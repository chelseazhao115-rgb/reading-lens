# Iteration 050 — P005反馈从类别标签到证据级对应

## Before

- P005认为“同义替换错误”技术上正确但教学价值不足：页面没有说明具体漏掉哪组表达、如何对应、下一次怎么检查。
- 当前`feedbackFor`仅按一级错因返回通用模板。

## Change

- 每道原创演示题增加服务端作者标注的题干表达、原文表达与对应解释。
- 同义替换诊断新增“这题具体漏掉了什么”：展示题干原词、原文原词、关系解释和立即可执行动作。
- 对应表达必须逐字存在于权威题干和passage；公开题目接口移除该教学Gold，避免提前泄露。
- 其他错因仍使用原有反馈，不伪造不存在的语义对应。

## After

- 159/159项自动化测试通过；合成框架评测保持12/12，未出现安全回退。
- 真实`/api/diagnose`请求返回作者标注的精确对应：`Cars were banned` ↔ `prohibited private cars from entering`，并给出关系解释和立即动作。
- 隔离研究会话的浏览器端到端回归确认：页面正确显示“题干表达—原文表达—对应解释—下一步动作”，同时仍生成同义替换微练习。
- 该修改解决的是P005指出的产品缺口；是否真正提高教学价值仍需由后续新用户验证，不能由实现者自行宣称。

## Regression

- 标准证据、答案和诊断支持元数据均只在服务端；模型不能自由发明quote或对应关系。
