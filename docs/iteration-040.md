# Iteration 040 — 作者QA与独立教师Gold双轨

## Before

- 用户本人具有雅思阅读教学经验，同时也是项目和候选案例的参与者；原审核流程只验证教师资质，没有验证审核者是否独立于案例编写。
- 项目作者可以技术上完成50条审核并进入Gold，导致“教师一致率”实际变成作者对自己标签的确认。
- 如果先用现有字段保存作者QA，后续独立教师可能看到作者标签或覆盖作者记录，无法同时保留样本质量检查和独立评测。

## Change

- 建立`author_qa`与`independent_teacher_gold`两条隔离轨道。
- 作者QA写入候选的独立嵌套记录，使用独立版本令牌、协议`diagnostic-author-qa-v1`和进度；不会修改独立教师字段，不进入Gold。
- 独立教师Gold除雅思阅读教师资质外，强制`independence_attested=true`，声明未参与案例编写或标签设计。
- 独立页面不下发或展示作者QA判断；作者页面明确标注结果仅用于检查证据、答案、标签边界和材料质量。
- 增加独立API与页面入口，更新CSV字段、启动说明、邀请模板和正式Gold门槛文本。

## After

- 自动化测试由141项增至143项，全部通过。
- 单元回归证明：合格作者QA可以保存和统计，但独立页面仍显示pending，Gold计数为0；仅有教师资质、没有独立性声明的记录被服务端拒绝。
- 运行时作者API与独立教师API均为0条真实审核；两者均不下发内部ID，独立API不含`author_qa`。
- 浏览器作者页显示“先检查样本，再邀请独立教师”，独立页显示“未参与案例编写”的Gold准入条件。
- 冻结预测完整性继续通过，正式Gold 0/50，所有官方教师指标保持N/A。

## Regression

- 24条历史流程测试记录继续保留并排除，不自动升级为独立教师记录。
- 作者QA不会泄露给后续独立审核者，也不会替代50条Gold。
- CSV离线导入新增`independence_attested`和`review_track`，缺少字段的旧文件不能进入新版Gold。
- 本轮未提交模拟审核，作者QA与独立试审真实进度均为0。
