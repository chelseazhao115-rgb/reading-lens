# Iteration 061 — 微练习独立教师交接与动态续审

## Before

- v3独立教师准入、盲审零泄露和未保存保护已经实现，但外部教师只能直接进入审核表单。
- 没有独立的资格说明、两阶段协议、六维规则、邀请文案或权威进度入口。
- 审核页面会自动找待审题，但不支持交接链接指定`?case=N`，动态启动页无法准确恢复到某一题。

## Change

- 新增`/exercise-review-start.html`，集中说明独立教师资格、两阶段不可倒序、六维判断、未保存保护和证据声明边界。
- 新增可直接发送的匿名邀请模板，明确预计时间、作者回避、数据最小化和“不证明提分”。
- 启动页从`/api/exercise-reviews`读取权威状态，区分0题、部分完成和10题完成，并在全部完成前只显示计数、不显示总体比例。
- 审核页支持`?case=N`定位；动态CTA可恢复到下一条pending练习。
- 新增3项纯状态测试及启动页静态回归，覆盖首次启动、部分续审和全部完成。

## After

- 177/177项自动化测试通过。
- 浏览器在0/10状态显示“先盲判，再揭示Gold”、零泄露边界、邀请模板和“开始10题独立盲审”。
- CTA指向`/exercise-review.html?case=1`；手工访问`?case=4`准确显示`EXERCISE 4 / 10`。
- 权威服务端仍为盲判0/10，浏览器验收没有提交教师结论。

## Regression

- 启动页只消费公开盲审API，不访问内部ID、答案、目标错因或阶段。
- 动态续审不修改审核记录；保存与Gold揭示仍由v3服务端协议控制。
- 本轮降低外部审核交接成本，但没有增加独立教师证据数量。
