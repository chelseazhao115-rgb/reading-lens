# Iteration 012 — Frozen Predictions and Gold Calibration

## Before

- The 50 candidates stored an author-authored `proposed_primary_error`, not a frozen engine prediction.
- Twelve candidates differed between that author hypothesis and the actual deterministic engine output.
- Official metrics compared teacher labels with the author hypothesis, which could misstate model quality.
- Teacher-Gold confidence calibration and high-confidence error monitoring did not exist.

## Change

- Generated a frozen prediction snapshot for every candidate: actual predicted label, confidence, status, teacher-review flag, provider, prompt version and model version.
- Changed official metrics to compare teacher Gold only against `predicted_primary_error`.
- Added prediction-snapshot integrity checks to server loading/saving, CSV import and eval execution.
- Removed author hypotheses, predictions and confidence from both blind browser payloads and review CSV.
- Added four required confidence buckets, average confidence, accuracy, calibration gap, ECE, high-confidence error rate and warning flag.

## After

- 65/65 tests pass (before: 64/64).
- All 41 JavaScript files pass syntax checks.
- Blind API verified 50 pending cases and exposed none of proposed label, predicted label or confidence.
- A test-only teacher-label fixture reports the actual rule baseline at Accuracy 0.75 and Macro F1 0.764, rather than the incorrect 1.00 implied by author hypotheses.
- Fixture calibration proves the four buckets and warning logic execute; these values are not official teacher results.
- Current official metrics remain unavailable because real Gold is 0/50.

## Regression

- No product, exercise, analytics or usability regression.
- Review CSV remains blind and import reconstructs only trusted snapshots from known IDs.
- No reviewed file was generated by tests or verification.

## Next

- Complete teacher review to replace the fixture with real Gold calibration.
- Add boundary-pair error reporting for the four most important confusion pairs.
- Use reviewed failures to create permanent regression cases before changing the diagnostic engine.
