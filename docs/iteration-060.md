# Iteration 060 — 微练习独立教师v3准入

## Before

- 微练习审核只要求雅思阅读教师资质和非测试编号，没有要求审核者未参与练习、答案或目标标签编写。
- 项目作者可以审核自己的练习，并在六项通过时被计入`teacher_validity`与两项盲判一致率。
- 这会把作者自审包装成外部教师证据；当前审核仍为0/10，尚未产生此类污染记录。

## Change

- 协议冻结为`exercise-two-stage-v3`，正式准入同时要求：
  - `teacher-`格式的稳定匿名编号；
  - 雅思阅读教师/教研资质；
  - `independence_attested=true`；
  - `review_track=independent_teacher_exercise`；
  - 未参与练习、答案或目标标签的编写。
- 浏览器在提交前拒绝`author-`及其他非`teacher-`编号，并明确展示独立性声明。
- 服务端在锁定盲判前再次验证全部准入条件；第二阶段保存及最终指标也只接受同一v3来源。
- CSV导出/导入增加独立性与审核轨道字段；旧v2记录不会自动升级或进入正式指标。
- 审核版本令牌纳入独立性、轨道和协议版本，防止旧页面覆盖v3状态。

## After

- 173/173项自动化测试通过。
- 运行时使用`author-001`且伪称独立，服务端返回`independent_reviewer_attestation_required`。
- 使用合格`teacher-001`但不确认独立性，同样被拒绝。
- 浏览器输入`author-001`时在本地阻止揭示Gold，并提示必须使用`teacher-`编号。
- 权威审核进度保持盲判0/10、Gold 0/10、教师有效率N/A。

## Regression

- 本轮没有生成、修改或升级任何教师审核结论。
- 项目作者仍可检查产品和测试代码，但其判断不能被记录为独立微练习教师证据。
- 真实外部教师仍需完成全部10题后，才计算有效率与盲判一致率。
