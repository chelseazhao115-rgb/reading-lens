# Iteration 046 — 独立教师检查点与付费模型离线评测入口

## Before

- 独立教师首批10条已完成，但尚未形成项目内审计记录。
- 8条Provider边界题只能通过手工fixture比较；没有可执行的真实模型适配器，也没有调用前预算预留保护。

## Change

- 固化独立教师10条检查点与9/10探索性一致结果，并明确正式指标仍需50条Gold。
- 新增OpenAI-compatible Responses适配层，并按产品负责人决定配置为DeepSeek官方API、`deepseek-v4-flash`、JSON Schema输出、固定Prompt版本和用量计费记录。
- 新增调用前最坏成本预留和调用后累计成本双重闸门；8条命令使用保守的0.60美元硬上限，低于用户批准的人民币5元。
- API Key只从服务端环境变量读取；缺失时在任何付费调用前失败。

## After

- 真实模型评测路径强制先跑1条smoke；成功记录存在后才能运行其余7条，并进入既有安全、质量、覆盖、契约、延迟和预算晋级门槛。
- 2026-08-31已完成DeepSeek真实评测。1条smoke正确且全部门槛通过；随后运行其余7条。
- 合并8条结果：4/8精确分类正确（50%），4/8为错误的确定性诊断（Unsafe Diagnosis Rate 50%），拒答率0%，输出契约失败率0%。
- 主要混淆：2条`paraphrase`均被判为`sentence_comprehension`；2条`question_strategy`均被判为`over_inference`。四个错误均输出0.85置信度，说明当前模型置信度不可直接信任。
- P95延迟约2.126秒；总成本0.00143766美元，远低于0.60美元硬上限。
- DeepSeek候选未通过安全晋级门槛，不接入学生端；下一轮优先修正类别操作定义与边界判定，再使用同一8条集回归。
